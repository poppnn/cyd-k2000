CYD K2000 dB

Décibelmètre pour Cheap Yellow Display (ESP32-2432S028R), affiché façon K2000. Se flashe depuis le navigateur.

Installer

Branche le CYD en USB, puis :

Navigateur non compatible : utilise Chrome ou Edge sur ordinateur (Web Serial). Le flash demande une page en HTTPS.

Si le port n'apparaît pas, installe le pilote USB CH340 de la carte.

Bon à savoir

  • Mesure en dB non pondéré (pas dB(A)), à quelques dB près : calibre CAL_OFFSET dans src/main.cpp avec un sonomètre de référence.
  • Prévu pour le CYD 2,8" à touch résistif (ILI9341, couleurs inversées corrigées). Couleurs fausses sur une autre version : retire TFT_INVERSION_ON dans platformio.ini et recompile.
  • Le niveau est aussi envoyé sur le port série (115200 bauds).
  • Sources : github.com/poppnn/cyd-k2000.
